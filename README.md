# arrudafranco.com

Research portfolio of Gustavo Arruda Franco, moved from Wix to GitHub Pages.

- `index.html`: home page
- `resume/`, `cases/`: Resume and Cases pages
- `post/<slug>/`: one folder per case study (same URLs as the old Wix site)
- `assets/style.css`: all styling
- `images/`: images, video and CV

To edit a page, change its `index.html` and commit. The site redeploys automatically.
To add a case, copy one of the `post/` folders, edit it, and add a card for it on `index.html` and `cases/index.html`.
